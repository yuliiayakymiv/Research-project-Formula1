# Research-project-Formula1

**Does the Starting Grid Decide the Race? A Statistical Analysis of Formula 1 (1950–2026)**

Team research project for the Probability Theory and Mathematical Statistics course.

## Data
Source: [Formula 1 World Championship (1950–2026), Kaggle](https://www.kaggle.com/datasets/samuelpombourcq/formula-1-world-championship-1950-2026)
Ergast-style tables, 1950 to the 2026 Mexico City GP (1,168 races). All CSVs are in `data/`.

## Structure
- `data/`: raw CSV files from Kaggle
- `plots/`: saved figures
- `interim_report.Rmd`: one-page interim report
- `final_report.Rmd`: final report (knit to HTML for submission)
